# pepe.coffee Tip Button: the Chrome extension is now live
The "pepe.coffee Tip Button" Chrome extension (version 1.3.1) is now
live and published in the Chrome Web Store, as of November 2026. It
adds a one-click "Tip" button directly on Reddit, X (Twitter), Twitch,
and Kick, so a visitor can tip a creator in Pepecoin (PEP) without
ever leaving the page they are already on. There is a dedicated guide
page at pepe.coffee/extension, translated into all of pepe.coffee's
supported languages, that explains the 5 steps to use it.

## pepe.coffee Tip Button: Reddit and X support
On Reddit, the pepe.coffee Tip Button extension adds a tip button
next to posts and comments, and this works on both new and old
Reddit. On X (Twitter), the tip button appears right in the action
bar underneath each post, next to the usual reply/repost/like icons.

## pepe.coffee Tip Button: Twitch and Kick support
On Twitch and Kick, the pepe.coffee Tip Button extension adds a tip
button next to the channel's "Follow" button; if the page layout
differs, a floating tip button appears instead as a fallback. On
Kick, usernames written with an underscore or a hyphen (such as
my_name and my-name) are treated as the exact same channel for
tipping purposes.

## pepe.coffee Tip Button: airdrop to commenters
On a Reddit thread or an X post, the pepe.coffee Tip Button extension
offers an "Airdrop to commenters/repliers" button that sends PEP to
everyone who commented or replied and already has a pepe.coffee page
— up to 2,000 recipients in a single transaction. Before sending, the
sender picks the same amount for everyone or splits one total amount,
sees the full recipient list with the option to remove people, and
sees the total network fee and their own balance. People who
commented but have no pepe.coffee page yet get a ready-made invite
message instead of a payment.

## pepe.coffee Tip Button: one-click wallet in the extension
The pepe.coffee Tip Button extension has a built-in one-click wallet:
a user logs in once inside the extension's own panel, and their
password never leaves their browser — it is not sent to pepe.coffee's
server. After that one login, every further tip is a single click.
The wallet key is stored as a key the browser itself will not let any
script read out, and the wallet automatically locks again after 30
minutes without use.

## pepe.coffee Tip Button: paying without an account
Someone who does not want to create a pepe.coffee account or install
the extension's wallet can still pay a tip generated by the pepe.coffee
Tip Button by scanning its QR code or copying the payment address and
paying from any Pepecoin wallet they already use. The payment is still
detected and credited automatically — no pepe.coffee account is
required to pay this way.

## pepe.coffee Tip Button: privacy and platform limits
The pepe.coffee Tip Button extension only contacts the pepe.coffee
server when a visitor actually clicks a Tip or Airdrop button — it
does not track general browsing in the background. Like all Chrome
extensions, it currently only works on desktop/laptop Chrome, not on
mobile Chrome. Without installing the extension at all, tipping still
works everywhere through the direct links pepe.coffee/reddit/name,
pepe.coffee/twitter/name, pepe.coffee/twitch/name, and
pepe.coffee/kick/name.

## pepe.coffee Tip Button: how creators enable it
A pepe.coffee creator enables the Tip Button extension for their own
content by adding their Reddit, X, Twitch, or Kick username in their
own pepe.coffee account dashboard. Once that username is saved,
anyone who has the extension installed can tip that creator directly
on Reddit, X, Twitch, or Kick, right where they already see that
creator's posts or stream — no extra setup needed on the creator's
side beyond entering the username once.

## pepe.coffee Tip Button: no official platform association
The pepe.coffee Tip Button extension and its pepe.coffee/extension
guide page both state clearly that the extension has no official
association with Reddit, X, Twitch, Kick, or Google — it is an
independent, third-party browser extension built by pepe.coffee, not
a feature offered by those platforms themselves.
